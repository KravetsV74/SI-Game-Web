# SI-Game-Web

## Концепция проекта

**SI-Game-Web** — локальное веб-приложение для проведения игры "Своя игра" в компании друзей.

Приложение запускается на устройстве ведущего (например, ноутбуке) и предоставляет участникам возможность подключаться через браузер с телефонов по локальной сети.

Цель проекта — создать удобную интерактивную версию "Своей игры" с разделением ролей, управлением ведущим, синхронизацией состояния игры и возможностью дальнейшего расширения механик.

---

# Основная идея

Игра проводится в формате:

* один ведущий управляет процессом;
* несколько игроков отвечают на вопросы;
* зрители могут наблюдать за игровым процессом на отдельном экране.

Все пользователи подключаются к одной игровой сессии.

Ведущий является главным управляющим игры:

* запускает игру;
* выбирает вопросы;
* контролирует ответы;
* начисляет и снимает очки;
* управляет переходами между состояниями игры.

---

# Роли пользователей

## Ведущий

Основной управляющий игры.

Обычно используется:

* ноутбук;
* компьютер.

Возможности ведущего:

* видеть список подключившихся игроков;
* запускать игру;
* выбирать начало раунда;
* выбирать тему и номинал вопроса;
* видеть правильный ответ;
* видеть, кто первым нажал кнопку ответа;
* засчитывать или отклонять ответы;
* вручную изменять количество очков игроков;
* управлять состоянием игры.

Примеры ручного изменения очков:

* игрок допустил ошибку, которую нужно исправить;
* игрок дал нестандартный, но хороший ответ;
* ведущий хочет добавить бонусные баллы.

---

## Игрок

Пользователь, принимающий участие в игре.

Подключение:

1. Пользователь выбирает роль "Игрок".
2. Вводит своё имя.
3. Нажимает кнопку "Начать".
4. Попадает в лобби ожидания.

После подключения игрок видит:

* состояние игры;
* доступные вопросы;
* своё количество очков;
* очки других игроков;
* информацию о том, кто отвечает.

Во время вопроса игрок может:

* нажать кнопку "Ответить";
* попытаться первым дать ответ.

Ограничения:

* отвечать может только один игрок одновременно;
* игроки, уже ошибившиеся в текущем вопросе, не могут повторно отвечать;
* если первый игрок ответил неправильно, остальные игроки получают возможность нажать кнопку ответа.

---

## Зритель

Отдельная роль для отображения игры на большом экране.

Использование:

* телевизор;
* второй ноутбук;
* проектор.

Зритель видит:

* игровое поле;
* игроков;
* количество очков;
* текущий вопрос;
* кто отвечает в данный момент.

Зритель не имеет доступа к:

* управлению игрой;
* правильным ответам до момента раскрытия;
* кнопкам ведущего.

# Сценарий игры

## 1. Подключение

При открытии приложения пользователь видит приветственный экран:

> Своя игра от Виктории Кравец!

Дополнительное сообщение:

> Добро пожаловать в эксклюзивную (не очень) версию SI Games!

Пользователь выбирает роль:

* Игрок;
* Ведущий;
* Зритель.

---

# 2. Лобби ожидания

После входа игроки попадают в ожидание.

Игрок видит:

```
Ожидаем начала игры...

Игроки:
- Виктория
- Алексей
- Мария
```

Ведущий видит уведомления:

```
Виктория присоединилась к игре

Алексей присоединился к игре
```

После того как все участники подключились, ведущий нажимает:

```
Начать игру
```

---

# 3. Заставка начала игры

После запуска отображается анимация начала раунда.

Темы игры красиво появляются на экране:

* движение снизу вверх;
* эффект пролистывания;
* постепенное появление списка тем.

После завершения анимации все пользователи переходят к игровому полю.

---

# 4. Игровое поле

Игровое поле имеет классическую структуру "Своей игры":

Темы расположены вертикально.

Номиналы расположены горизонтально.

Пример:

```
              100   200   300   400

История        □     □     □     □

Наука          □     □     □     □

Кино           □     □     □     □

Игры           □     □     □     □
```

Под игровым полем отображаются игроки:

```
Игроки:

Виктория       500
Алексей        300
Мария          100
```

Также отображается последний ответивший игрок.

Например:

```
Последний ответ:

Виктория
```

Это необходимо для будущих игровых модификаторов и удобства ведущего.

---

# 5. Выбор вопроса

Игроки не выбирают вопросы самостоятельно.

Ведущий нажимает выбранную клетку:

Например:

```
История - 300
```

После выбора вопрос становится активным.

---

# 6. Отображение задания

После выбора:

* текст вопроса;
* изображение;
* дополнительные материалы

последовательно загружаются и отображаются у всех участников.

Возможное будущее улучшение:

* защита от фальш-старта;
* блокировка кнопки ответа до полной загрузки задания;
* специальные эффекты появления вопроса.

---

# 7. Ответы игроков

У игроков появляется большая кнопка:

```
Ответить
```

Первый нажавший игрок становится отвечающим.

У всех пользователей отображается:

```
Отвечает:

Виктория
```

Остальные игроки временно не могут нажать кнопку ответа.

---

# 8. Проверка ответа

Ведущий видит:

```
Игрок:

Виктория


Ответ:

...


Правильный ответ:

1945
```

Доступны действия:

```
Верно
Ошибка
```

---

# 9. Правильный ответ

Если игрок ответил правильно:

* правильный ответ автоматически отображается;
* игрок получает очки;
* через небольшой промежуток времени все возвращаются к игровому полю.

Пример:

```
Виктория +300

Очки:
Виктория 800
```

---

# 10. Неправильный ответ

Если игрок ошибся:

* с игрока снимаются очки;
* игрок больше не может отвечать на этот вопрос;
* остальные игроки получают возможность ответить.

Пример:

```
Виктория -300

Другие игроки могут отвечать
```

---

# Игровая логика

Основное состояние игры должно храниться централизованно.

Пример состояния:

* список игроков;
* их очки;
* текущий вопрос;
* выбранная тема;
* выбранный номинал;
* кто отвечает;
* кто уже ошибся;
* последний ответивший игрок;
* состояние игры.

---

# Возможные будущие расширения

```
- Виктория

```

---

Возможность:

* сохранять результаты;

* загружать подготовленные наборы вопросов.
